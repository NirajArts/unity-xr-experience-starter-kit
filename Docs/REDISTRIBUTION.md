# Origin and redistribution

The reference project's owner explicitly authorized reuse of their custom scripts, Grip Editor and skills. The kit reuses the generic Grip Editor and bounded bridge, and generalizes the raw-wrist rigid-fit algorithm. Their original file hashes are in `Reports/REUSED_FILES.json`; extraction changes are in `Reports/EXTRACTION.md`.

The generic demo, runtime assembly system, authored meshes/materials, documentation, skills and six synthesized WAVs were created for this repository. MIT covers authored/owner-authorized kit content. It does not cover Unity, Meta or NUnit assets/code installed through UPM.

Excluded content includes production models, textures, training sequences, proprietary requirements, narration/video, logos, client button graphics, purchased assets, credentials, machine settings, source Git history, Blender authoring and package caches. An inactive object or disabled renderer is not an acceptable way to include excluded material.

SDK rig/hand/canvas and base-pose references resolve inside official packages. Keep their applicable notices when packaging a derivative and follow their SDK distribution terms. This starter does not assert that an SDK may be repackaged as a standalone Asset Store product. Your own eventual marketplace submission needs its own dependency and license review.

Open questions for a downstream product: platform distribution terms, owned/licensed content added later, analytics/privacy permissions if introduced, and the chosen license for new proprietary modules. No such third-party production content was needed for this demo.
